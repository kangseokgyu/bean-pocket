# 커피 레시피 북에 핸드드립 레시피 등록

사용자가 앱에 등록해 달라고 한 레시피만 저장한다. 레시피 목록에 나오고 추출 시작점으로 선택할 수 있는 공용 레시피를 만든다. 일반 Notion 문서나 비공개 초안으로 대신하지 않는다. 에스프레소는 핸드드립 단계로 변환하지 않는다.

## 저장 전

1. 제목, 원두량(g), 물 온도(℃), 총 주입량(g), 각 단계의 시작 시각과 주입량을 정리한다. 시작 시각은 영상 타임스탬프가 아니라 추출 시작 기준 초다. 아이스 레시피의 얼음은 총 주입량에서 제외하고 추출 가이드에 적는다. 온도 범위만 주어졌다면 범위 내 기준 온도 하나를 선택하고 가이드에 원래 범위를 남긴다. 필수 계량이나 단계가 빠졌거나 서로 모순되면 추측해 저장하지 않는다.
2. 여러 레시피라면 모두 먼저 검증한다. 저장소 루트의 [도메인 함수](../../../lib/domain.mjs) `validateRecipe`에 단계별 `name`, `seconds`, `water`를 전달하고 반환된 `steps`를 쓰기 값으로 사용한다. 이 함수가 1부터 시작하는 순서, 직전 단계와의 시간 간격, 누적 물 양을 계산하고 총 주입량을 검사한다. [앱의 Notion 속성 매핑](../../../pwa/data/notion-properties.mjs)의 `recipes`와 `steps`를 참고한다.
3. 연결된 Notion에서 사용자가 지정한 앱 데이터 소스를 확인한다. 별도 지정이 없으면 ‘커피 레시피 북’ 상위 페이지를 찾아 그 아래의 **레시피**와 **물 붓기 단계**를 읽는다. 데이터베이스의 `collection://` 데이터 소스 URL, 현재 속성 이름·타입, 단계의 ‘레시피’ 관계가 해당 레시피 데이터 소스를 가리키는지 확인한다. 여러 후보가 있고 어느 것이 앱 연결인지 확인할 수 없으면 저장 전에 확인한다. 개인 페이지 ID나 연결 토큰을 스킬 또는 저장소에 적지 않는다.
4. 원본 데이터 소스에서 같은 제목이나 같은 출처의 레시피를 조회한다. 원두 관계로 필터된 Notion 뷰만 보고 없다고 판단하지 않는다. 동일한 완성 레시피는 다시 만들지 않는다. 기존 항목의 조건이 다르거나 불완전하면 무단으로 덮어쓰지 않는다. 이번 등록에서 생성한 항목의 이어쓰기라면 아래 복구 절차를 따른다.

## 저장

1. 현재 Notion 도구의 페이지 생성 계약과 Markdown 명세를 읽는다. 각 레시피를 **레시피 데이터 소스의 행**으로 생성하고 반환된 페이지 ID와 URL을 제목에 대응시킨다. 원두 관계는 비워 둔다. 앱의 ‘추출 가이드’ 속성에 목표 완료 시간, 필터, 얼음, 주입 팁 등 추출에 필요한 설명을 남긴다. 입자 굵기가 범위로만 제공되면 ‘분쇄도’에 범위를 보존한다. 영상 출처와 시연 타임스탬프 링크는 페이지 본문에 둔다.
2. 각 단계는 **물 붓기 단계 데이터 소스의 행**으로 생성한다. ‘레시피’ 관계에 바로 앞에서 확인한 부모 페이지 하나만 연결한다. Notion 페이지 생성 도구에는 이 관계를 해당 레시피 페이지 URL 하나를 담은 배열로 전달한다. 단계 이름·순서·누적 시간·간격·이번에 붓는 물 양·누적 물 양을 모두 저장한다.
3. 결과가 불명확하거나 일부 단계만 저장됐으면 재시도 전에 부모와 연결된 단계를 다시 읽는다. 이번 작업의 부모임이 확인되고 기존 단계가 의도한 값과 모두 일치할 때만 빠진 순서를 추가한다. 중복 순서나 충돌이 있거나 부모를 특정할 수 없으면 쓰기를 멈추고 남은 항목을 알린다.

## 검증과 안내

- 생성 응답만으로 완료를 판단하지 않는다. 두 데이터 소스에서 저장된 부모와 자식 행을 다시 조회해 레시피 조건, 부모 관계, 단계 개수와 모든 수치를 원래 등록값과 대조한다. SQL 조회에서 URL 문자열이 달라 일치하지 않으면 페이지 ID로 대조한다.
- 읽어 온 단계들을 순서대로 정렬해 부모에 붙인 뒤 `validateStoredRecipe`로 검사한다. 빠진 단계가 있거나 검증에 실패한 레시피를 앱에서 사용할 수 있다고 보고하지 않는다.
- 등록·검증한 레시피 이름을 알려 주고, [bean-pocket](https://kangseokgyu.github.io/bean-pocket/)의 **레시피** 탭에서 새로고침 후 검색하도록 안내한다. 실제 앱 화면까지 확인했는지, 데이터와 앱 검증 함수만 확인했는지 구분한다.
