# 개인용 PWA에서 Notion에 직접 연결

2026-10-17 인터뷰에서 본인만 사용하는 레시피 북은 PC가 꺼진 상태와 외부 셀룰러 환경에서도 실행하고 PC 웹 지원도 유지하기로 했다. 사용자는 HTTPS 정적 호스팅의 PWA에서 Notion에 직접 연결하는 안을 선택했다. 별도 서버리스 API와 접근 인증을 운영하지 않는 직접 통신 방식을 선택했다. 최초에는 기기별 토큰 암호화 보관과 암호 해제를 선택했으나, 후속 지시에 따라 첫 버전에서 암호화·암호 입력을 제외했다. 최신 지시로 토큰을 앱 내부 파일에 보관하고 재실행 시 자동 연결하며, 잠금·잠금 해제도 구현하지 않기로 했다. 앱 삭제 시 해당 설치의 토큰·설정이 함께 삭제되어야 한다. PWA의 OPFS는 보관 후보이며 앱 삭제 후 재설치 시 저장값 부재를 실기기에서 검증해야 한다. 이 조건을 충족하지 못하면 실행 방식을 다시 결정한다. 실행 중 키는 해당 기기의 앱 코드가 사용할 수 있다는 절충을 포함한다.

실제 iPhone에서 조회·신규 추가·레시피 복사 검증을 통과해야 채택하며 아직 구현·실기기 검증은 하지 않았다. 검증 실패 시 원인을 확인하고 서버리스 API 등 대안을 다시 결정한다. 첫 배포는 무료 범위로 제한하며 유료 전환은 별도로 결정한다. 로컬 서버는 개발·검증에 활용하고 iOS 패키지 설치는 이번 목표에서 제외한다. 후속 Q10 답변에 따라 기존 항목 수정은 미구현으로 유지하며 앱 내 삭제도 이번 범위에 포함하지 않는다.

최신 사용자 지시로 외부 호스팅 없이 iPhone에 직접 설치·업데이트하는 방식으로 전환했다. 현재 결정은 [ADR-0002](0002-direct-iphone-test-installation.md)를 따른다.

현재 확정 방향은 [ADR-0003](0003-github-pages-personal-pwa.md)의 GitHub Pages PWA다.
