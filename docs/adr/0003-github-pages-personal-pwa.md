# 개인용 PWA를 GitHub Pages에 배포

2026-10-17 Q24에서 사용자는 네이티브 iPhone 앱 대신 GitHub Pages PWA를 확정했다. Mac·Xcode를 통한 설치·서명과 별도 호스팅 공급자 구성을 피하고, iPhone 홈 화면과 PC 브라우저에서 같은 정적 사이트를 사용한다. 앱 시작·새로고침·저장 성공 후 Notion에 직접 조회하며 조회·신규 추가·레시피 복사를 제공한다. 기존 항목 수정·삭제와 오프라인 데이터 처리는 제외한다. [ADR-0001](0001-personal-pwa-direct-notion.md)과 [ADR-0002](0002-direct-iphone-test-installation.md)의 과거 방향을 대체한다.

사용자가 지정한 대로 토큰은 기기의 앱 전용 파일에 보관하고 자동 연결하며 앱 자체 암호화·암호 입력·잠금·잠금 해제를 추가하지 않는다. PWA의 OPFS가 후보이지만 앱 삭제 시 토큰 제거 요구는 iPhone 12 / iOS 27.0.1에서 검증해야 한다. 아직 지원을 확인한 것은 아니며, 실패하면 임의로 요구를 완화하거나 네이티브 앱으로 전환하지 않는다. 토큰·실제 데이터는 저장소와 배포 파일에 포함하지 않는다.

GitHub Pages의 무료 이용을 목표로 하되 실제 계정·저장소 조건을 확인하고 공개 전환은 임의로 하지 않는다. 원격 설정과 배포는 아직 수행하지 않았다. 기술 확인·상세 완료 기준은 [인터뷰 확정사항](../iphone-interview.md)을 따른다.
