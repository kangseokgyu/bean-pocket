# Bean Pocket 버튼과 아이콘 가이드

같은 행동에는 화면이 달라도 같은 아이콘과 이름을 쓴다. 자리가 좁으면 버튼의 배경과 라벨을 먼저 줄인다. 실제로 누를 수 있는 영역은 따로 정한다.

## 버튼의 역할

| 역할 | 표시 | 예 |
| --- | --- | --- |
| 주요 행동 | 채운 배경과 짧은 라벨. 화면이나 대화상자에서 가장 중요한 행동 하나에 쓴다. 아이콘은 뜻을 보탤 때 붙인다. | **추출 기록**, **저장** |
| 보조 행동 | 라벨이나 옅은 테두리로 표시한다. 결과가 아이콘만으로 분명하지 않으면 글자를 남긴다. | **취소**, **다시 시도** |
| 화면 이동 | 화살표와 목적지를 함께 표시한다. 목적지가 보이는 목록 복귀 버튼은 테두리 없이 둔다. | **← 레시피 목록**, **← 원두 목록** |
| 익숙한 도구 | 위치와 뜻이 분명하면 아이콘만 쓴다. 나란히 있는 도구는 같은 크기와 테두리로 묶는다. | 수정, 복사, 삭제 확인 열기 |
| 삭제 확정 | 삭제할 대상을 확인창에 표시한다. 빨간색과 **삭제** 라벨은 확정 버튼에 쓴다. | 레시피 삭제 확인 |
| 목록 이어 보기 | 목록 끝에 넓게 배치한다. | **더 불러오기** |

## 원두·레시피 목록과 상세, 설정 헤더

- 원두와 레시피 목록은 카드 왼쪽에 제목, 오른쪽 위에 별을 둔다. 삭제는 상세 화면의 휴지통에서 시작한다.
- 레시피 상세의 첫 줄은 왼쪽에 **← 레시피 목록**, 오른쪽에 **수정 → 복사 → 삭제** 순서다. 연필, 겹친 문서, 휴지통을 각각 쓴다. 휴지통은 확인창을 열고, 복사는 원본을 채운 새 레시피 폼을 연다.
- 원두 상세의 첫 줄은 왼쪽에 **← 원두 목록**, 오른쪽에 **즐겨찾기 → 삭제** 순서다. 즐겨찾기는 별, 삭제 확인은 휴지통을 쓴다.
- 원두와 레시피 카드의 제목 오른쪽에는 컵 아이콘과 **추출 기록**을 둔다. 버튼을 누르면 해당 원두 또는 레시피가 선택된 기록 폼이 열린다.
- 앱 헤더 오른쪽에는 테두리 없이 설정 톱니를 표시한다. 설정을 열면 둥근 배경으로 열린 상태를 표시한다. 레시피 상세의 편집 도구는 둥근 사각형으로 둔다.

| 위치 | 보이는 크기 | 누를 수 있는 영역 |
| --- | --- | --- |
| 원두·레시피 목록 즐겨찾기 | 22 × 22px 별 아이콘 | 44 × 44px |
| 원두·레시피 상세 상단 아이콘 | 22 × 22px 아이콘, 44 × 44px 테두리 | 44 × 44px |
| 원두·레시피 상세 추출 기록 | 18 × 18px 컵 아이콘, 32px 높이의 채운 배경 | 높이 44px 이상 |
| 설정 톱니 | 22 × 22px 아이콘 | 44 × 44px |
| 목록으로 돌아가기 | 화살표와 목적지 라벨 | 높이 44px 이상 |

크기는 CSS px 기준이다. 새 모바일 버튼은 44 × 44px 이상의 터치 영역을 기본값으로 잡는다. 아이콘 크기를 줄여도 터치 영역을 함께 줄이지 않는다.

## 이름과 상태

- 아이콘만 있는 버튼에는 동작을 읽어 주는 접근성 이름을 붙인다. 예: `이 레시피 복사`, `Notion 연결 설정`. SVG는 장식으로 처리한다.
- 키보드 초점을 표시하고, 클릭·터치·키보드에서 같은 동작을 실행한다. 열린 상태는 `aria-expanded`, 즐겨찾기처럼 눌린 상태는 `aria-pressed`로 전달한다.
- 저장이 진행 중이면 진행 문구를 표시하고 중복 제출을 막는다. 성공과 실패는 색 외에 문구로도 알린다. 삭제는 확인창에서 대상을 읽을 수 있게 하고 취소할 수 있게 한다.

## 구현과 검증

버튼은 [공용 버튼 모듈](../pwa/ui/shared/buttons.mjs), 아이콘은 [공용 아이콘 모듈](../pwa/ui/shared/icons.mjs)에서 재사용한다. 크기, 색, 테두리는 [스타일시트](../pwa/styles.css)에 둔다. [원두 상세](../pwa/ui/screens/beans.mjs)와 [레시피 상세](../pwa/ui/screens/recipes.mjs)에는 버튼의 위치와 동작을 지정한다.

공개 PWA에는 직접 그린 SVG나 웹 배포가 허용된 아이콘을 쓴다. Apple의 디자인 지침은 참고할 수 있지만, [Apple SDK 약관](https://www.apple.com/legal/sla/docs/xcode.pdf#page=6)에 따라 SF Symbols 원본은 이 PWA에 배포하지 않는다. [Lucide](https://lucide.dev/license) 등 외부 SVG를 가져오면 해당 자산의 저작권 및 라이선스 고지를 배포본에 함께 둔다.

버튼을 바꿀 때는 좁은 화면과 데스크톱에서 긴 제목, 터치 영역과 버튼 사이 간격, 키보드 초점, 눌렀을 때 열리는 폼이나 확인창을 확인한다. 테스트와 게시 명령은 [Pages 배포 안내](pages-deploy.md)를 따른다.
