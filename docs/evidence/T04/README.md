## 사용자 확인 절차

1. 설정에서 실제 기종과 iOS 버전을 확인한다.
2. Safari에서 위 주소를 열고 원두 목록·Notion 연결 전 안내·빌드 버전을 확인한다.
3. 공유 → 홈 화면에 추가를 실행한다.
4. 홈 화면의 아이콘으로 실행해 화면과 기본 터치, 글자 잘림 여부를 확인한다.
5. 홈 화면 앱을 종료한 뒤 다시 실행하고 같은 화면·빌드가 보이는지 확인한다.
6. 기종·iOS, Safari 결과, 홈 화면 실행 및 재실행 결과, 확인 시각을 알려준다.

Safari 접속, 홈 화면 추가, 홈 화면 실행, 종료·재실행은 모두 **미검증**이다. 사용자 결과를 받으면 이 기록을 갱신한다. PC의 실제 Pages 성공을 아이폰 성공으로 대체하지 않는다. 이 단계는 Notion 연결·저장이나 파일 보관 실험을 포함하지 않는다.
