# T07 앱 전용 파일 보관 — 실험판 준비 및 PC 일부 검증

2026-10-18 (Asia/Seoul). 실제 iPhone의 Safari·홈 화면 및 종료·재실행 검증은 대기다.

실험판 `pwa/probes/storage/`는 OPFS 전용 하위 폴더의 버전 JSON에 `T07-DEMO-` 형식의 가짜 문자열만 작성한다. 토큰·연결 정보는 입력하지 않는다. 읽기는 파일이나 폴더를 생성하지 않는다. 미지원·파일 없음·권한·용량·손상·경로 충돌을 구분하며 삭제나 다른 저장소로의 대체 기능은 없다.

1. 새 시험 시작 확인을 체크하고 가짜 파일을 작성한다.
2. 작성·읽기의 식별값을 대조하고 빌드·실행 모드·기기·OS와 함께 기록한다.
3. 종료·재실행 후 **읽기만** 실행한다. 업데이트·삭제·재설치 측정 중에 다시 작성하면 측정이 바뀐다.
4. T08은 같은 출처·scope의 A/B 업데이트와 홈 화면 설치 완전 삭제·재설치 순서로 별도 진행한다. 사이트 데이터 수동 삭제나 앱 내부 파일 삭제로 대체하지 않는다.

로컬 PC 인앱 브라우저의 `http://localhost:4189/bean-pocket/probes/storage/`에서 가짜 파일 작성 → 페이지 새로고침 → 기존 파일 읽기를 확인했다. [화면](local-storage.png). PC 앱 완전 종료·업데이트·삭제·재설치 및 실기기 보관 수명은 확인하지 않았다. 로컬 결과는 T07/T08 실기기 통과의 근거가 아니다.

독립 검토의 식별값 누락 지적을 수정했다. 전체 시험 JSON의 SHA-256을 작성·읽기에 표시하며, 회귀 테스트에서 같은 파일·모듈 재생성과 다른 유효 파일을 구별했다. 지문 미지원·실패 시 새 파일을 쓰기 전에 차단한다. 독립 재검토 PASS.

최종 실험판 빌드 `7a9015e1e222`에서 새 가짜 파일 작성 → 새로고침 → 읽기의 지문이 `b237f26916f08a8f527c206cf9b71c4c4af941237c93988f925d3eaa1a05dc16`으로 같음을 화면에서 확인했다. 이는 새로고침 검증이며 앱 완전 종료나 업데이트 유지 검증으로 세지 않는다.
