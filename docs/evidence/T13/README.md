# T13 연결 파일 저장소 — 구현 검증

T10 확정 계약을 기준으로 worker-2 Locke(gpt-6-luna/max)가 연결 파일 어댑터를 구현했다. 활성 연결 교체·작업 journal·배타 제어의 통합은 T14/T21 후속 범위이며, 이 어댑터만으로 다른 창의 제출 안전성을 완료했다고 보고하지 않는다.

## 실제 로컬 브라우저 확인

로컬 정적 경로의 최종 실험 빌드 `31d43a080478`에서 실제 모듈 import, 모의 조회, 가짜 연결 OPFS 저장·재읽기 및 탭 종료→재접속→기존 연결 읽기의 동일 세대·값을 확인했다. [화면](local-foundation.png). 실제 토큰이나 Notion 쓰기는 사용하지 않았다. 후속 공백 토큰 수정 반영 빌드로 다시 import하고 기존 가짜 연결 읽기 PASS도 확인했다.

이는 PC 로컬 브라우저의 탭 재접속 결과이며 iPhone·브라우저 프로세스 완전 종료·연결 교체 통합·삭제 수명 보장으로 확대하지 않는다. **T29에서 최종 실제 연결 파일 수명을 재검증**한다. 현재 Pages 시험판과 사용자 기존 실기기 시험 파일은 변경하지 않았다.

최초 독립 critic 검토는 전용 32개 테스트로 PASS였고, 공백 토큰 수정 반영 후 최종 검토에서도 PASS를 유지했다. 코드 커밋 `0e2450f`, 공용 빌드 통합 `843a886`.
