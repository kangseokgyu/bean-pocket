# T18 레시피·단계 생성 명령

모든 단계의 Notion 전송 가능성을 부모 생성 전에 미리 검사하고, 최신 원두 존재를 lock 안에서 재검증한 뒤 레시피를 만들고 단계를 N→1 역순으로 직렬 저장한다. 명확한 실패에는 확인된 현재 작업의 부모를 먼저 archive하고 성공 확인 뒤 자식을 취소한다. unknown이면 추가 원격 쓰기를 하지 않는다. 실제 T15 조회에서 order 1이 없는 부분 레시피가 제외되는 것도 검증했다.

전용·영향 테스트는 [T16~T20 통합 검증 로그](../T16/affected-green.txt)에 기록했다.
