# T25 — 레시피 작성·복사

새 레시피와 복사본은 같은 폼을 쓴다. 양수·온도·선택 μm, 시간 순서·총량은 공유 명령/도메인 검증을 따른다. 단계 미리보기는 누적 시간·간격·이번 물 양·누적 물 양을 나란히 보여주며 초안 단계 값을 탭 이동·재조회 후 보존한다. 원본 ID·평가·기록은 복사하지 않는다.

- GREEN: [T21–T26 UI 전용 실행 결과](../T26/ui-test-green.txt), real controller/command/client/repository와 synthetic Notion으로 신규·복사 흐름 포함
- 부모 CUA 보고: 소수 dose·μm, 3단계 작성 후 독립 복사와 조건 변경 확인. 부분/unknown 복구 최종 확인은 부모 전용 QA 대상이다.
