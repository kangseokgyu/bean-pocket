# 추출 기록 데모 — 화면 계약

## 목적

샘플 추출 기록만으로 원두별 최고 평가 추출과 당시 레시피·조건·컵노트를 훑고 비교한다. 기존 기록 화면과 저장·Notion 연결은 유지한다.

## 화면 구조와 동작

- 작은 샘플 안내와 기록 화면으로 돌아가는 링크를 표시한다. 샘플 데이터는 실제 사용자 기록이나 연결 데이터가 아님을 명확히 쓴다.
- 원두 선택 목록에 원두 3종 이상, 각 원두의 최고 평점, 추출일, 레시피, 기록 표본 수를 요약한다.
- 선택한 원두의 최고 평가 추출에 별점, 추출 날짜, 로스팅 후 경과일, 레시피, 분쇄, 온도, 도징, 물 양, 추출 시간을 표시한다.
- 최고 기록은 사용자 입력 권장값이 아니라 샘플 기록에서 계산한다. 평가 동점이면 최근 기록을 대표 기록으로 삼고, 표본 수와 동점 처리 기준을 함께 알린다.
- 비교 영역은 날짜, 로스팅 후 경과일, 레시피, 분쇄·온도·도징·물·시간, 평가, 컵노트를 보여준다. 좁은 화면에서는 각 기록을 카드로 읽게 한다.
- 원두 선택, 레시피 필터, 날짜·평가 정렬을 제공한다. 필터 결과가 없을 때 설명이 있는 빈 상태를 보인다.

## 표현과 제약

- 기존 PWA ivory/coffee 색상(`#f3efe6`, `#fbf9f4`, `#203d32`)을 사용하고, 큰 마케팅 hero 대신 원두 목록과 비교 정보를 우선한다.
- 단순 DOM JavaScript만 사용하고 의존성, 원격 요청, 브라우저 영속 저장소를 추가하지 않는다.
- 페이지는 일반 Pages 빌드의 명시적 허용 파일·빌드 해시·보안 검사·Service Worker 프리캐시에 포함한다.
- 본화면에는 데모 진입 링크만 작게 추가한다.

## 완료 조건

- 계산·필터·정렬과 공개 산출물 경계 테스트를 RED→GREEN으로 확인한다.
- `npm test`, `npm run build:pages`, `npm run check:pages`를 실행한다.
- 로컬 브라우저에서 320, 768, 1024, 1440 px 폭과 원두 선택, 필터, 정렬, 빈 상태, 콘솔·요청을 확인하고 화면 캡처를 남긴다.
