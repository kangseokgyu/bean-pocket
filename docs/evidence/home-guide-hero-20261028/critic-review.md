# 독립 리뷰

- 판정: 승인. 수정이 필요한 기능·접근성·보안·회귀 문제를 발견하지 않았다.
- 대상: `486866c`와 기준 `6635ff2`의 변경. 홈 렌더링, 홈 전용 CSS, 테스트와 검증 문서로 범위가 제한되어 있다.
- 요구사항: 영문 eyebrow, 기존 제목, 승인 보조 문구, 컵·화살표 CTA와 브라운 SVG 드리퍼·서버를 확인했다. 다른 화면·내비게이션·푸터 구현은 변경하지 않았다. 그림은 시안의 음영 표현을 단순한 선화로 구현했다.
- 독립 확인: 승인 시안과 1280px 실제 브라우저 미리보기를 비교했다. 접근성 트리에서 제목과 이름 있는 추출 시작 버튼을 확인했으며 장식 SVG는 숨겨져 있다. 기존 focus-visible 규칙, 중첩 아이콘 클릭의 closest 위임과 start-brew 경로 유지도 검토했다. `git diff --check 6635ff2` 종료 코드 0.
- 검증 근거: Worker 로그의 전체 테스트 610/610, 실패·건너뜀 0, Pages 빌드와 산출물 검사 통과를 확인했다. 빌드 버전 `0b2385480db2`. CSS와 view 소스가 빌드 해시에 포함되어 서비스 워커 캐시 버전이 갱신된다. 변경 없는 전체 테스트를 중복 실행하지 않았다.
- 한계: 독립 시각 확인은 제작 view/CSS를 불러오는 임시 미리보기에서 수행했다. 원래 PWA의 OPFS 저장소 초기화 이후 시작 흐름과 공개 배포는 이 리뷰에서 검증하지 않았다. 320/390/768px 확인과 CTA 클릭 결과는 Worker 기록을 근거로 한다. CUA 화면 캡처는 인라인 이미지로 확인했으며 저장된 PNG는 없다.
