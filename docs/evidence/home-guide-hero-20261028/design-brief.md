# 04-guide 홈 히어로 디자인 브리프

- 승인 시안: `/Users/kangseokgyu/.codex/visualizations/2026/10/28/01a182b5-60f5-7cb2-9803-abbdc2738e77/home-demos/04-guide.png`
- 범위: 기존 앱의 홈 히어로만 교체한다. 전역 내비게이션, 푸터, 다른 화면은 유지한다.
- 화면 역할: 오늘의 추출을 시작하도록 핵심 메시지와 단일 CTA를 빠르게 전달한다.
- 순서: `GOOD COFFEE / BRIGHTER DAYS` → 오늘의 한 잔 헤드라인 → 원두와 기록에 관한 보조 문구 → `추출 시작` CTA.
- 색과 그림: 기존 아이보리 배경과 진한 초록을 바탕으로, 브라운 선화 드리퍼·서버를 SVG로 표현한다.
- 반응형: 600px 초과에서는 텍스트와 그림을 2열로 놓고, 600px 이하에서는 CTA 아래에 그림을 쌓는다. 320px에서 가로 스크롤 없이 읽고 누를 수 있어야 한다.
- 동작과 접근성: CTA의 기존 `start-brew` 동작을 유지한다. SVG 장식은 스크린 리더에서 숨긴다.
