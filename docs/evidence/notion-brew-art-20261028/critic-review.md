# 독립 리뷰

- 판정: 소스·이미지 검토 승인. 수정이 필요한 기능·접근성·보안·패키징 문제를 발견하지 않았다.
- 기준: `94605b5` 이후 이미지 교체 변경. 제목·보조 문구·CTA·레이아웃은 유지되고 SVG 본문과 전용 선화 스타일만 제거됐다. 장식 img는 빈 alt와 aria-hidden을 사용하며 크기 속성으로 정사각형 비율을 예약한다.
- PNG 원본을 직접 열어 사람이 주전자로 드리퍼에 물을 붓는 흑백 일러스트를 확인했다. 원본과 프로젝트 자산 SHA-256이 `5ca4eba24ca3a37de5d8363f08bb982f4ea2adea2e95daccd395a05a5ff4d8b2`로 일치한다.
- Pages 복사·검사 허용 목록과 서비스 워커 사전 캐시에 이미지가 포함됐다. 신규 테스트는 바이트 보존, 오프라인 캐시 등록과 이미지 변경 시 빌드 버전 갱신을 검사한다. 외부 URL·새 의존성·사용자 입력 처리가 추가되지 않았다. `git diff --check 94605b5` 종료 코드 0.
- Worker 보고: 전체 테스트 611/611, 빌드 버전 `41bc06ad0638`, Pages 검사 통과. 변경 없는 전체 검증을 중복 실행하지 않았다.
- 브라우저 한계: 독립 CUA getState는 browsers가 빈 배열이며 iab 탭 접근도 불가했다. Safari는 사용하지 않았다. 390/1280px 실제 렌더링, 이미지 로드, overflow와 CTA 클릭은 이 리뷰에서 확인하지 못했으며 정상 IAB 세션이 있는 Orchestrator에게 검증을 요청했다. 공개 배포와 정상 PWA 시작도 이번 리뷰의 검증 범위 밖이다.
