## 2026-10-18 실험판 검증 보완

같은 orchestrator → worker → critic을 기존 모델·추론 설정으로 재사용했다. 부모는 단일 도메인 원본 공급·일반/실험 빌드 경계·workflow·통합 검증을 담당했고 worker는 직접 통신과 OPFS 실험을 테스트 선행으로 구현했다. critic은 변경분과 명세를 독립 검토했다. 최종 전체 테스트 79통과, 일반·실험 빌드 검사 통과, critic 재검토 PASS. PC의 직접 가짜 인증 401과 OPFS 작성·새로고침·동일 지문 읽기를 확인했다. 결과는 각 T06/T07/T11 증거에 기록했다.

일반 빌드에는 실험 경로가 없으며 명시적 실험 빌드만 정확한 네 파일과 홈 메뉴를 포함한다. 원래 도메인 파일은 수정하지 않고 산출물·버전·앱 캐시에 포함한다. 실제 Pages 게시와 실기기 통과는 로컬·모의 검증과 구분한다.

검증 대상 코드 커밋: `d282d2d` (실험판 준비·단일 도메인 공급). 일반 빌드 `0c1d6e2a1967`, 실험판 `7a9015e1e222`. 사용자 승인 후 `7aa0c54`까지 main에 통합하고 실험판을 게시했다. [게시 기록](evidence/T06/pages-deploy.md). 실기기 게이트는 대기다.
