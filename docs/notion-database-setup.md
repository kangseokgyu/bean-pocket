# 노션 데이터베이스 구성

## 작업 범위

현재 연결된 노션 워크스페이스 최상위에 ‘커피 레시피 북’ 전용 페이지를 만들고 관련 데이터베이스를 연결한다. 별도 웹사이트는 이번 데이터베이스 생성 작업에 포함하지 않는다.

## 데이터 구분

- 원두: 원두 이름과 로스터리·원산지·품종·가공 방식·로스터리 향미 노트.
- 원두 봉지: 구매한 봉지별 원두 관계와 로스팅 날짜.
- 레시피: 특정 원두의 추출 조건. 조건 변경은 별도 레시피로 구분한다.
- 물 붓기 단계: 레시피별 단계 순서, 시간과 물 양.
- 추출 기록: 특정 레시피와 사용한 봉지, 날짜·별점·컵노트.

## 확인할 항목

- 전용 페이지가 최상위에 있고 모든 데이터베이스가 그 아래에 있는가.
- 원두와 봉지·레시피, 레시피와 단계·추출 기록, 봉지와 추출 기록의 관계 대상이 올바른가.
- 물 붓기 단계의 시간·간격·물 양·누적 물 양이 한 행에 표시되는가.
- 레시피별 평균 별점과 평가 횟수의 계산 대상이 올바른가.
- 과거 추출 조건 보존을 위한 저장 항목이 있으며, 아직 구현하지 않은 자동 동작을 명확히 구분했는가.
- 실제 데이터로 오인할 예시 원두나 평가가 없는가.

## 구현 경계

노션 데이터베이스를 만드는 것과 웹사이트의 입력 검증·복사·당시 조건 보존 동작을 구현하는 것은 별개다. 웹사이트에서 필요한 저장 동작은 후속 구현에서 검증한다.

## 생성 결과

커피 레시피 북 전용 페이지와 아래 5개 데이터베이스를 구성했다. 개인 워크스페이스 이름, 페이지 주소와 실제 식별자는 공개 문서에 포함하지 않는다. 본인의 데이터 소스 ID는 Git에서 제외된 `.env.local` 또는 서버 환경변수에 설정한다.

| 데이터베이스 | 데이터 소스 ID 환경변수 |
|---|---|
| 원두 | `NOTION_BEANS_DATA_SOURCE_ID` |
| 원두 봉지 | `NOTION_BAGS_DATA_SOURCE_ID` |
| 레시피 | `NOTION_RECIPES_DATA_SOURCE_ID` |
| 물 붓기 단계 | `NOTION_STEPS_DATA_SOURCE_ID` |
| 추출 기록 | `NOTION_RECORDS_DATA_SOURCE_ID` |

관련 항목은 양방향 관계로 연결했다. 레시피의 평균 별점은 관련 추출 기록의 별점 평균 집계로 구성했다. 평가 횟수는 `prop("추출 기록").length()` 수식으로 연결된 기록 수를 세므로 같은 별점이 반복되어도 각각 집계한다.

전용 페이지에는 원두 목록, 레시피와 평가, 시간·물 양 한 행, 최근 추출 기록 인라인 뷰를 배치했다. 물 붓기 단계는 레시피별로 묶고 순서대로 표시한다.

## 검증 상태

워커와 크리틱이 생성 후 페이지·관계·뷰 설정을 다시 읽어 확인했다. 각 데이터베이스는 비어 있으며, 임의의 원두나 평가를 넣지 않았다. 평균과 횟수는 설정을 확인했지만 실제 기록을 이용한 수치 검증은 하지 않았다.

초기 평가 횟수 집계의 중복값 처리 의미가 불명확하다는 크리틱 지적에 따라, 연결된 기록 목록의 길이를 세는 수식으로 변경했다. 변경 후 수식 타입, 평균 별점 집계 유지, 기본·인라인 뷰 설정 유지를 확인했다. 조회 도구가 수식 본문을 코드 URL로만 반환하므로 원문 재조회는 하지 못했으며, 적용 DDL은 위 수식이다. 크리틱 재검토에서 페이지·데이터베이스 구성 범위는 통과했다. 저장된 수식 원문과 실제 데이터의 계산값을 독립 검증한 것은 아니다.

## 로컬 웹사이트 구현 현황

- 웹사이트에서 간격·누적 물 양 자동 계산과 총 물 양 일치 확인을 구현했다. 노션에서 직접 입력할 때 자동 계산되는 수식은 아니다.
- 레시피와 모든 물 붓기 단계의 복사 저장을 구현했다.
- 웹사이트에서 추출 기록을 저장할 때 당시 조건과 모든 단계를 보존하는 동작을 구현했다.
- 날짜·별점 필수 입력, 별점 정수 1~5, 단일 관계, 레시피와 봉지의 원두 일치 검증을 구현했다.
- 실제 노션 쓰기 검증은 로컬 앱용 연결 키 설정 후 남아 있다. 모의 통신 테스트와 브라우저 체험 모드 검증 결과는 [검증 기록](verification.md)에 구분했다.

노션에서 직접 추출 기록을 입력하는 경우에는 데이터베이스 연결만으로 당시 조건이 자동 보존되지 않는다.
