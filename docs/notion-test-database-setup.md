# Notion 테스트 데이터 소스 — T05

기준: `fc9be86`의 PLAN T05, `lib/notion.mjs`의 쓰기 속성 계약. 운영 원본과 분리된 빈 테스트 DB 5개를 준비한다. 실제 페이지 주소·식별자·스키마 원문은 Git에서 제외된 `.state/`에만 보관하며 이 공개 문서에는 넣지 않는다.

## 속성 대응표

기존 코드가 쓰는 속성 33개를 같은 이름·타입으로 보존한다. relation의 대상은 모두 테스트 데이터 소스다.

| DB | 속성 | 타입 |
|---|---|---|
| 원두 | 원두 이름 | title |
| 원두 | 로스터리, 원산지·농장, 품종, 가공 방식, 로스터리 향미 노트 | rich_text |
| 원두 봉지 | 봉지 이름 | title |
| 원두 봉지 | 원두 | relation → 테스트 원두 |
| 원두 봉지 | 로스팅 날짜 | date |
| 레시피 | 레시피 이름 | title |
| 레시피 | 원두 | relation → 테스트 원두 |
| 레시피 | 드리퍼, 분쇄도, 그라인더 이름, 그라인더 설정값 | rich_text |
| 레시피 | 원두 사용량(g), 분쇄 입자 굵기(μm), 물 온도(℃), 총 물 양(g) | number |
| 물 붓기 단계 | 단계 이름 | title |
| 물 붓기 단계 | 레시피 | relation → 테스트 레시피 |
| 물 붓기 단계 | 순서, 누적 시간(초), 간격(초), 이번에 붓는 물 양(g), 누적 물 양(g) | number |
| 추출 기록 | 기록 이름 | title |
| 추출 기록 | 레시피 | relation → 테스트 레시피 |
| 추출 기록 | 원두 봉지 | relation → 테스트 원두 봉지 (입력 선택) |
| 추출 기록 | 날짜 | date |
| 추출 기록 | 별점 | number |
| 추출 기록 | 컵노트, 당시 레시피 스냅샷 | rich_text |

양방향 관계에는 원두의 봉지·레시피 목록, 레시피의 단계·추출 기록 목록, 봉지의 추출 기록 목록이 대응한다. 레시피의 평균 별점은 `추출 기록` 관계가 가리키는 `별점`의 평균이다. 평가 횟수는 `prop("추출 기록").length()`로 연결된 기록 수를 센다.

스냅샷은 JSON을 담는 rich_text이며, DB 생성만으로 과거 조건이 자동 보존되지는 않는다. 별점의 정수 1~5, 단일 관계와 봉지·레시피 원두 일치 검증은 애플리케이션에서 수행해야 한다. 이 준비 작업에서 운영 DB나 애플리케이션 로직을 변경하지 않는다.

## 접근과 검증 경계

Notion 커넥터의 사용자 권한으로 스키마를 생성·수정하는 것과 iPhone에서 입력할 내부 연결 토큰의 권한은 다르다. 테스트 부모 페이지의 연결 메뉴에서 앱용 내부 연결에 접근을 허용해야 할 수 있다. 읽기·콘텐츠 삽입·내부 복구용 수정 권한을 확인하되, 임의 레코드를 넣어 권한 확인에 갈음하지 않는다.

최종 생성·빈 목록·관계·집계·권한 확인 결과와 미검증 범위는 [T05 증거](evidence/T05/README.md)에 기록한다. 실제 iPhone의 교차 출처 조회·생성·오류 읽기는 T06이며, 커넥터나 Node의 성공으로 대신하지 않는다.
