# 레시피 북 인터뷰 확정사항

- 핸드드립 커피 레시피를 저장하는 레시피 북을 만든다.
- 개인용으로 시작한다.
- 날짜, 평가, 컵노트를 기록한다.
- 전체 만족도를 별점 1~5점으로 평가한다.
- 하나의 원두에 여러 레시피를 저장할 수 있다.
- 하나의 레시피에 날짜별로 여러 추출 기록을 남길 수 있다.
- 같은 날 같은 레시피로 여러 번 내려 마셔도, 추출마다 별도의 기록을 남길 수 있다.
- 추출 기록에는 날짜, 전체 만족도 별점 1~5점, 컵노트를 기록한다.
- 추출 기록의 날짜와 별점은 필수이며, 컵노트는 선택 입력한다.
- 추출 조건이 달라지면 별도의 레시피로 구분한다. 추출 기록에서 레시피의 조건을 개별적으로 변경하지 않는다.
- 기존 레시피를 복사한 뒤 필요한 항목을 변경해 새 레시피로 저장할 수 있게 한다.
- 레시피 항목은 레시피 이름, 드리퍼, 원두 사용량, 분쇄도, 물 온도, 총 물 양, 단계별 물 붓기(시간과 물 양)이다.
- 물 붓기 각 단계에 누적 시간과 간격을 모두 표시한다.
- 각 물 붓기 단계에 이번에 붓는 물 양과 누적 물 양을 모두 표시한다.
- 각 단계의 누적 시간, 간격, 이번에 붓는 물 양, 누적 물 양을 한 행에 함께 표시한다.
- 분쇄도에 원두 입자 굵기를 마이크론(μm) 단위로 저장할 수 있게 한다. 사용자가 언급한 기준은 언스페셜티 분쇄도 가이드이다.
- 분쇄 입자 굵기의 마이크론(μm) 값은 사용자가 직접 입력한다.
- 원두 정보는 원두 이름, 로스터리, 원산지·농장, 품종, 가공 방식, 로스터리가 안내한 향미 노트로 구성한다. 로스팅 날짜는 구매한 봉지별로 관리한다.
- 원두 정보 중 원두 이름만 필수이며, 나머지는 선택 입력한다.
- 로스터리가 안내한 향미 노트와 추출 기록에 직접 작성하는 컵노트는 구분해 저장한다.
- 같은 원두를 다시 구매해도 원두 정보와 레시피를 이어 쓰고, 구매한 봉지는 별도로 관리한다.
- 추출 기록에는 사용한 원두 봉지를 연결해 어느 봉지로 내렸는지 기록할 수 있게 한다.
- 레시피를 수정해도 기존 추출 기록에는 추출 당시 사용한 레시피의 조건을 보존한다. 예를 들어 물 온도를 93℃에서 90℃로 수정해도 과거 기록의 물 온도는 93℃로 유지한다.
- 휴대폰과 PC에서 모두 사용할 수 있게 하며, 휴대폰 화면을 우선으로 구성한다.
- 현재 버전의 웹사이트에는 로그인이나 계정별 접근 제한을 두지 않는다. 휴대폰과 PC에서는 같은 노션 데이터를 조회하고 저장한다.
- 첫 버전은 인터넷 연결을 전제로 사용한다. 오프라인 조회·기록과 재연결 후 동기화는 이후로 미룬다.
- 첫 버전은 레시피 표시와 추출 기록에 집중한다. 추출 타이머는 이후로 미루며, 첫 버전에서는 별도의 타이머나 저울을 함께 사용한다.
- 첫 화면은 원두 목록으로 구성한다. 원두를 선택하면 레시피 목록으로, 레시피를 선택하면 추출 방법과 날짜별 평가·컵노트로 이동한다.
- 레시피 목록에 각 레시피의 평균 별점과 평가 횟수를 함께 표시한다.
- 컵노트는 정해진 향미 목록에서 선택하는 대신 자유롭게 글로 입력한다.
- 원두·원두 봉지·레시피·추출 기록을 모두 노션 데이터베이스에 저장하고 서로 연결한다.
- 사용 화면은 휴대폰과 PC에 대응하는 별도 웹사이트로 만들고, 데이터 저장소는 노션으로 한다.
- 현재 연결된 노션 워크스페이스 최상위에 전용 ‘커피 레시피 북’ 페이지를 만들고 관련 데이터베이스를 모은다.
- 생성된 페이지와 데이터베이스 정보는 [노션 구성 기록](notion-database-setup.md)에 정리한다.
- 웹사이트는 우선 이 컴퓨터에서 실행하며 기능을 확인한 뒤 배포한다.
