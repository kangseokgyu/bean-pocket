## 허용 범위

실험 화면 보완, 실기기 실행 안내와 결과 수집, 증거 정리까지 진행한다. 사용자가 이미 허용한 T10 계약 초안과 T11 순수 로직 정적 공급의 사전 준비는 유지한다. T10 최종 확정 및 T12 이후 전체 기능 이전은 차단한다.

실패가 확인되면 원인과 요구·구조 변경 대안을 제시하고 사용자의 결정에 따라 SPEC·ADR·PLAN 변경을 검토한다. 미검증을 통과로 바꾸거나 프록시·운영 서버·네이티브·다른 저장 정책을 임의 도입하지 않는다.
