Bean Pocket UI 모듈 지도

실제 소스의 정적 import를 바탕으로 생성한 유지보수용 지도다. 파일명·줄 수·직접 의존성을 확인하고, 수정할 영역부터 검색할 수 있다.

app.mjs에서 View와 Controller를 조립한다. 아래 화살표 목록은 각 파일이 직접 import하는 파일을 뜻한다. 상태·초안·안전성의 세부 계약은 docs/ui-refactoring.md에서 확인한다.

이 문서는 동적 호출 그래프나 실기기 검증 결과가 아니다. 외부 자원 없이 열 수 있다. 재생성은 build-diagram.mjs에 체크아웃 루트와 출력 파일 경로를 전달한다.
