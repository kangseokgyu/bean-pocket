# 로컬 웹사이트 검증

## 브라우저에서 확인한 흐름

실제 노션 연결 키가 없는 상태에서, 노션과 분리된 체험 모드로 확인했다. 체험 모드는 데이터를 탭 메모리에만 저장하고, 노션 저장이 아니라는 안내를 표시한다.

- 첫 화면에 원두 목록과 빈 상태, 노션 연결 및 체험 시작 버튼이 표시된다.
- 원두 선택 후 레시피 목록, 레시피 선택 후 추출 조건·물 붓기 단계·추출 기록으로 이동한다.
- 단계별 누적 시간, 간격, 이번에 붓는 물 양과 누적 물 양이 같은 행에 표시된다.
- 날짜·4점 별점·자유 입력 컵노트를 남기면 기록에 반영된다.
- 93℃ 원본을 복사해 90℃ 레시피를 저장하면 원본은 93℃·평가 1회, 복사본은 90℃·평가 0회로 구분된다.
- 좁은 화면에서 탐색과 입력 창이 표시되고, 물 붓기 표는 내부에서 가로 스크롤한다. 브라우저의 임시 화면 크기 설정은 검증 후 해제했다.

## 검증 경계

실제 노션 저장은 로컬 앱용 연결 키와 전용 페이지 접근 설정 후 확인해야 한다. 채팅의 Notion 연결 상태나 모의 통신 테스트 통과로 실제 저장 검증을 대신하지 않는다.

## 자동 테스트와 독립 검토

- 구현 전 모듈 부재로 테스트 파일 3개가 실패하는 것을 확인한 뒤 구현했다.
- 초기 18개 테스트가 통과한 후 크리틱이 단계 수정 재시도, 일시 오류 캐시, 생성 중 레시피의 불완전 스냅샷 문제를 재현했다.
- 신규 회귀 테스트 3개의 실패를 확인하고 수정했다. 추가 경계 검증을 포함한 최종 결과는 24개 테스트 통과다.
- JavaScript·MJS 파일 8개의 구문 검사가 통과했다.
- 크리틱이 직접 테스트와 구문 검사를 실행하고, 세 수정 사항을 재검토해 승인했다.
- 수정 후 브라우저에서 총 물 양 150g·단계 합계 250g으로 저장 오류를 확인하고, 중간 100g 단계를 삭제한 뒤 같은 양식으로 재저장하는 흐름이 성공했다. 이는 체험 모드의 UI 검증이며, 동일 요청 키의 서버 처리 검증은 모의 노션 HTTP 통합 테스트로 수행했다.

실제 Notion 저장·재조회는 아직 검증하지 않았다. 기존 노션에 테스트용 운영 레코드를 추가하지 않았다.
