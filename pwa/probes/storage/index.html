파일 읽기

읽기는 파일이나 폴더를 새로 만들지 않습니다. 재실행·업데이트·삭제·재설치 등 수행한 조작과 읽기 결과를 별도로 기록해 주세요. 파일 앱 다운로드나 다른 저장소로 우회하지 않습니다.

작성 결과의 SHA-256 지문을 기록하고 이후 읽기 지문과 대조하세요. 지문은 가짜 시험 문자열·버전·작성 시각을 담은 JSON 전체 내용의 식별값입니다. 원문은 표시하지 않으며 다른 시험 문자열이나 작성 내용은 다른 지문으로 구별합니다.
